# OPERATE

Scripts for cleaning Castor first-presentation records and developing diagnostic prediction models for definitive gallstone-related disease in patients presenting with abdominal pain after bariatric surgery.

Historical stages are retained for traceability: do not run all scripts sequentially. The initial withdrawn v3 output is not a valid input.

## Analysis design

One first episode per patient; SEH and POLI are separate. Prior cholecystectomy is excluded from both cases and controls. Definitive gallstone diagnoses require the documented diagnostic/procedural evidence within the index episode. Unresolved eligibility and identity decisions remain explicit exclusions. Structural nonmeasurement is not imputed.

The SEH laboratory model contains age, sex, years since bariatric surgery, RYGB code group, right upper abdominal pain, bilirubin, ALP, ALT and CRP. Laboratories use ln(1+x). The adjusted model uses ridge logistic regression, 50 imputations and bootstrap internal validation. The exploratory univariable analyses use ordinary logistic regression and Rubin pooling of the same 50 saved imputations; their estimators and intervals differ. Univariable findings do not select predictors.

## Running locally

This is a code snapshot for review. Private source exports, metadata, frozen cohorts and saved model inputs are required separately. No patient data, imputed data, predictions, fitted objects, clinical review workbooks, CRF documents or generated analysis outputs are included.

Keep the local folder name `OPERATE`; scripts generally expect execution from its parent or explicit project/release arguments. Read each header first: some files execute immediately when imported or sourced. This snapshot is not a single-command pipeline and was not analytically rerun for this transfer.

Examples requiring private inputs:

```sh
python3 OPERATE/analysis/23_freeze_analysis.py
python3 OPERATE/analysis/24_model_prepare_inputs.py
Rscript OPERATE/analysis/24_model_pipeline.R OPERATE/results/analysis_2026-10-27_no_adjudication
Rscript OPERATE/analysis/29_SEH_lab_univariable.R OPERATE
```

The model specification is generated by script 23. Python cleaning dependencies are in [requirements-cleaning.txt](analysis/requirements-cleaning.txt); report/metadata utilities also require packages listed in their imports. R stages use `mice`, `glmnet` and `jsonlite` plus dependencies. The univariable run recorded R 4.6.1. Local library/environment folders are excluded; dependencies are not a fully locked environment.
